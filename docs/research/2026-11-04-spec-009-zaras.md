## 2. M-150: a szűkített `plugins` gyökér és az al-agent (O-47)

**Kérdés.** Az M-147 A4 és A5 esete szerint az agent definíció al-agentje a `plugins` gyökér minden skilljét
látja és hívhatja, a lépés `skills` listájától függetlenül. Ha a gyökér csak a lépés kiválasztott
skilljeinek másolata, az al-agent is csak azokat látja-e; elfogadja-e a CLI az üres `skills/` mappájú
gyökeret; és a `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS=1` az al-agentre is hat-e.

**Felállás.** A 2026-10-28-i mérés segédjei (`2026-10-28-spec-009-blokkolo-meresek/csonk-messages-api.mjs`,
`sdk-betolto.mjs`): a pinelt SDK a `tools/wire-probe` telepítéséből, helyi Messages API csonk, hamis kulcs,
`settingSources: []`, `strictMcpConfig: true`, valódi API hívás nincs. A gyökér manifeszt nélküli,
`easter-skills` nevű mappa (a plugin neve a könyvtárnév, M-136 4a). Script: `2026-11-04-spec-009-zaras/m150.mjs`,
kimenet: `m150-kimenet.jsonl` (futtatás: `node m150.mjs > m150-kimenet.jsonl`).

| Eset | Gyökér, lépés `skills`, env                             | Az al-agent listázása (plugin skill) | Az al-agent hívása és eredménye                       |
| ---- | ------------------------------------------------------- | ------------------------------------ | ----------------------------------------------------- |
| C1   | csak `beta`, `['easter-skills:beta']`                   | csak `easter-skills:beta`            | `Skill easter-skills:alfa`: "Unknown skill"           |
| C2   | csak `beta`, `['easter-skills:beta']`                   | csak `easter-skills:beta`            | `Skill easter-skills:beta`: "Launching skill"         |
| C3   | üres `skills/` mappa, `[]`                              | nincs plugin skill                   | (nincs hívás); a futás `success`, a `query()` nem dob |
| C4   | nincs `plugins`, `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS=1` | a listázás üres (beépített sem)      | `Skill simplify`: "Unknown skill: simplify"           |
| C5   | nincs `plugins`, kapcsoló nélkül (a C4 kontrollja)      | a beépítettek listázva               | `Skill simplify`: betöltve                            |

**Megállapítás.** A szűkített gyökérből az al-agent csak a kiválasztott skillt látja és hívhatja (C1, C2), az üres
gyökér hibát nem okoz (C3), a kikapcsoló változó az al-agentre is hat (C4, C5). Az O-47 tehát kivitelezhető a
`plugins` gyökér lépésenkénti, a kiválasztott skillek másolatából álló változatával (`apps/server`
`createHardenedSdkQuery`, a lépés ideiglenes könyvtárában, a folyam végén törölve). A C4 `init` üzenetének
`skills` listájában a kikapcsoló mellett is állt egy név (`doctor`), a modell elé kerülő listázásban és a
hívhatóságban nem; hogy ez milyen eredetű, nem ellenőrzött.

## 3. T-012-12a: valódi próba skill és MCP opcióval

**Engedély.** A user 2026-11-04-én: "Igen, futhat". A kérdés pontosan: "skill és MCP egy valódi agent
lépésben, MiniMax-M3.1-Flash, egy kör, alacsony effort". Kizárólag a `minimax` provider, egyszer;
`claude-subscription` ellen semmi nem futott.

**Futtatás.** `node --env-file=<a user .env fájlja> apps/server/measurement/real-provider-probe.ts minimax --skill-mcp`
a `18aefd7` fejen (a gyökér `probe:real-provider` script megfelelője, a user `.env` fájljával). A próba saját
szervert indít ideiglenes adatbázissal, napló és skill könyvtár útvonallal; feltölt egy `proba-skill` skillt
(nyers ZIP), elment egy `proba-mcp` stdio MCP szervert (`apps/server/measurement/probe-mcp-stdio-server.ts`,
egyetlen `ping` eszköz), és a lépés (`MiniMax-M3.1-Flash`, `maxTurns: 1`, `effort: low`, rövid, eszközt nem kérő
prompt) a skillt kiválasztja és a szervert hivatkozza.

**Eredmény (a próba összegzése, változatlanul).**

```json
{
  "providerId": "minimax",
  "runStatus": "succeeded",
  "stepStatus": "succeeded",
  "resultSubtype": "success",
  "numTurns": 1,
  "outputTextLength": 83,
  "initPluginSkills": ["skills:proba-skill"],
  "initMcpServers": ["proba-mcp:connected"]
}
```

**Mit dönt el.** A valódi CLI a lépésenkénti, szűkített `plugins` gyökeret (O-47), a `0600` jogú MCP config
fájlt (O-52) és az indító programon át futó stdio szervert (O-45) együtt elfogadja: az `init` üzenet a
feltöltött skillt minősített néven listázza, az MCP szerver `connected` állapotú (tehát az O-46 ellenőrzés nem
állította meg), és a lépés egy körben `success` zárást ad. **Mit nem dönt el.** A modell a skillt és az MCP
eszközt nem hívta (a prompt eszközt nem kért, `maxTurns: 1`), tehát a hívás útja valódi providerrel nem mért;
az al-agent útja (M-150) csak a helyi csonk ellen mért. További futás nem történt.
