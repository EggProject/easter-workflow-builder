## 3. Mért tények (saját mérés, telepített Ajv 8.20.0, 2026-11-04)

- `{ type: 'string', format: 'email' }` fordítása: hiba, `unknown format "email" ignored in schema at path "#"`.
- `{ foo: 1 }`: hiba, `strict mode: unknown keyword: "foo"`.
- `$schema: 'https://json-schema.org/draft/2020-12/schema'`: hiba, `no schema with key or ref ...`.
- `$schema: 'http://json-schema.org/draft-07/schema#'`: lefordul.
- `true` logikai séma: lefordul, minden kimenetet elfogad.
- `{ type: 'number', minimum: 3 }` az `1` kimenetre: eltérés, `keyword: minimum`, `instancePath: ""`.

## 4. Nyitott kérdések (termékdöntés)

1. **A `format` kulcsszó.** (a) annotációként kezelni (`validateFormats: false`), mint az SDK (K-3, egy
   gyártói forrás); (b) formátumok ellenőrzése az `ajv-formats` csomaggal (új pinelt függőség); (c) marad a
   mai elutasítás. A mai viselkedés a spec szövege szerinti.
2. **A mentés mezőútjának szállítása.** (a) marad a mezőlista visszafejtése, egyetlen mezőre szűkítve
   (mai állapot); (b) a `ProtocolErrorBody` elhagyható, strukturált mezőútja (SPEC-005 8.1 módosítás).
3. **Az Ajv strict figyelmeztetései.** (a) marad a `console`; (b) kikapcsolás (`logger: false`); (c) a
   projekt naplózójába vezetés.
