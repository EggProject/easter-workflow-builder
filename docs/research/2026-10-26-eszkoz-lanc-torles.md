Dátum: 2026-10-26. Hatókör: a SPEC-011 tervezetének bizonyítékai. A user döntése (2026-10-26):
"minimaxmcp -t ki lehet dobni (törölni kell a kódját és minden ráutalást a dokumentációkból is!)",
pontosítva: "csak a gyári claude tool-ok maradnak". Minden szám ebben a fájlban saját, ezen a napon
futtatott mérésből vagy a commitolt fa `git grep` kimenetéből jön; a kiinduló fej a `main`
`6009603` commitja.

A user további döntései (2026-10-26, a SPEC-011 12. szekciójában): "nincs még adatbázis, nincs mit
migrálni", "nincs régi rajz", ezért az 1. szekció mérései **nem migrációt és nem tűrést**

- SQLite `3.53.4`, `better-sqlite3` `13.0.3` (a telepített csomagból kiolvasva).
- `update workflow_node set config = json_remove(config, '$.agentTools') where

  pillanatkép változatlan, az `agentTools` kulcs benne marad.

## 2. A gyári eszközök az Agent SDK-ban

Elsődleges forrás a telepített `@anthropic-ai/claude-agent-sdk` `0.3.245` típusdeklarációja
(`node_modules/.bun/@anthropic-ai+claude-agent-sdk@0.3.245+7b719043580c7622/node_modules/@anthropic-ai/claude-agent-sdk/sdk.d.ts`):

- `allowedTools` (`sdk.d.ts:1416-1422`): "List of tool names that are auto-allowed without
  prompting for permission ... To restrict which tools are available, use the `tools` option
  instead."
- `disallowedTools` (`sdk.d.ts:1437-1442`): "These tools will be removed from the model's context
  and cannot be used, even if they would otherwise be allowed."
- `tools` (`sdk.d.ts:1469-1478`): "Specify the base set of available built-in tools", `[]` minden
  beépített eszközt kikapcsol, a preset a teljes Claude Code készletet adja.
- A beépített eszközök bemeneti típusai között szerepel a `WebFetchInput` és a `WebSearchInput`
  (`sdk-tools.d.ts:30-31`, `:1009`, `:1019`).

Megerősítés, hivatalos dokumentáció (lekérdezve 2026-10-26):

1. <https://code.claude.com/docs/en/tools-reference>: a beépített eszközök táblázatában a
   `WebFetch` ("Fetches content from a specified URL", engedély kell) és a `WebSearch` ("Performs
   web searches", engedély kell). A "WebFetch tool behavior" szakasz: "For most fetches, it then
   runs the prompt against the content in a separate model call". A "WebSearch tool behavior"
   szakasz: "WebSearch runs a query against Anthropic's web search backend ... The search backend is
   not configurable."
2. <https://code.claude.com/docs/en/agent-sdk/permissions>: "`disallowed_tools=["Bash"]` The `Bash`
   tool definition is removed from the request"; "Any other tool not listed in `allowed_tools` is
   still available to Claude, and a call to it that needs approval falls through to the permission
   mode."
3. <https://code.claude.com/docs/en/agent-sdk/typescript>: az SDK verziója a csomagolt Claude Code
   verzióját követi ("SDK v0.3.191 bundles Claude Code v2.1.191").

**Nem ellenőrzött:** a permissions oldal "With Claude Code v2.1.302 or later, your app starts in
`default` mode ... Claude Code denies any tool call needing approval unless you approve it" mondata
a mi pinelt verziónknál (`0.3.245`, a 3. forrás szerint Claude Code `2.1.245`) újabb viselkedést ír
le; a mi verziónk viselkedését engedély nélküli `WebSearch` hívásra nem mértük. Ugyanígy nem
ellenőrzött, hogy a `WebFetch` "separate model call" hívása a `minimax` provider
`ANTHROPIC_BASE_URL` értékére megy-e, és ott mit ad.

A mai kód: a motor a lépés `allowedTools` és `disallowedTools` listáját adja át, a
`disallowedTools` a leíró szerint nem működő szerver oldali eszköz kliens nevével bővül
(`build-agent-step-options.ts:100-101`); `tools` opciót, `canUseTool` callbacket nem ad át (a
`packages/*/src` és `apps/*/src` termékkódjában nincs `canUseTool` találat). A `minimax` leíró a
`web_search` szerver oldali eszközt `available: false` értékkel, `clientToolName: 'WebSearch'`
bizonyítékkal hordozza (`provider-minimax/src/tool-support/server-tools.ts:7-26`, M-17, M-25),
tehát a `minimax` lépés kérésében a `WebSearch` a `disallowedTools` listán áll.
