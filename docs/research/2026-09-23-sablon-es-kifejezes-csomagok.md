# A Mustache és a CEL szállított csomagjainak forrásai (2026-09-23)

Ez a fájl a SPEC-010 bizonyítéka: a user 2026-09-23-i döntése (sablon nyelv: Mustache,
kifejezés nyelv: CEL) után azt rögzíti, **melyik npm csomag** valósítja meg a két nyelvet, és a
csomagok mely, dokumentált viselkedésére épít a spec. A jelöltek nyelvi szintű összevetése a
[`2026-09-23-sablon-es-kifejezes-nyelv.md`](2026-09-23-sablon-es-kifejezes-nyelv.md) fájlban áll;
ez a fájl azt nem ismétli meg.

Módszer: élő npm registry lekérdezés (`registry.npmjs.org`), a publikált csomag `package.json`
fájlja egy második, független CDN-ről (`unpkg.com`, `cdn.jsdelivr.net`), a publikált forrás és
README olvasása, a GitHub REST API (`api.github.com`) a karbantartottságra és a GitHub Advisory
Database-re. Minden verziószám és dátum a 2026-09-23-i állapot. A "saját mérés" jelölésű sorok
egy repón kívüli, eldobható könyvtárban futottak, a csomag telepítésével; a repó `bun.lock`
fájlja nem mozdult. **A SPEC-010 blokkoló mérése (PLAN-010 F0) ezeket a pinelt verzión, a valódi
`RunContext` alakon megismétli**; ez a fájl a döntés alapja, nem a végleges mérés.

## 6. Ellenpélda, amit kimondunk

A Microsoft Semantic Kernel a prompt sablonba illesztett tartalmat alapból HTML kódolja
(`AllowDangerouslySetContent`, alapértéke `false`). A dokumentált ok az, hogy a Semantic Kernel a
promptot XML szerű `<message role="...">` jelölésként **elemzi**, és a kódolás ez ellen az elemző
elleni befecskendezés ellen véd
(`https://learn.microsoft.com/en-us/semantic-kernel/concepts/prompts/prompt-injection-attacks`,
`https://learn.microsoft.com/en-us/dotnet/api/microsoft.semantickernel.prompttemplateconfig.allowdangerouslysetcontent`).
A mi motorunk a renderelt promptot nem elemzi, hanem változatlanul a `query()` `prompt` mezőjébe
adja (SPEC-004 3.3), tehát ez az ok ránk nem érvényes. A LangChain Python Mustache
implementációja szintén escape-el alapból; erre dokumentált indokot nem találtunk.

## 7. Saját mérés: a prototípus lánc a `mustache@4.2.0`-ban

Felállás: Node v26.7.0, a publikált `https://unpkg.com/mustache@4.2.0/mustache.js` fájl
változatlanul, repón kívüli, eldobható könyvtárban; nézet:
`{ input: { tema: 'x', items: ['a', 'b'] }, steps: {}, item: undefined }`; a `render` negyedik
argumentuma `{ escape: (v) => String(v) }`, a SPEC-010 6.1 szerint.

| Sablon                                   | Kimenet                                                                                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{{toString}}`                           | `[object Object]`                                                                                                                                             |
| `{{constructor}}`                        | `[object Object]`                                                                                                                                             |
| `{{input.constructor.name}}`             | `Object`                                                                                                                                                      |
| `{{input.constructor.constructor.name}}` | `Function`                                                                                                                                                    |
| `{{#constructor}}x{{/constructor}}`      | `x`                                                                                                                                                           |
| `{{input.items.constructor.name}}`       | `Array`                                                                                                                                                       |
| `{{input.tema.constructor.name}}`        | `String`                                                                                                                                                      |
| `{{input.items.map}}`                    | szinkron `TypeError` kivétel (`undefined is not a function`)                                                                                                  |
| `{{input.items.constructor.fromAsync}}`  | szinkron kimenet `[object Promise]`, **utána a folyamat `1` kilépési kóddal leállt** egy kezeletlen promise elutasítás miatt (`Array.fromAsync`, `TypeError`) |

**Következtetés.** A mustache.js név feloldása a `RunContext` adatán túl a JavaScript beépített
objektumaihoz is elér, és egy felhasználó által írt sablon a szerver folyamatát le tudja állítani
(5.5). Egy `try`/`catch` ezt nem fogja meg, mert az elutasítás a renderelés visszatérése után
történik. A SPEC-010 6.6 szekciója ezért a név feloldást saját adat tulajdonságra szűkíti.

## 8. Amit ez a fájl NEM állít

- **NEM MEGERŐSÍTETT**, hogy a `@marcbachmann/cel-js` a hivatalos conformance suite minden
  tételét teljesíti. A README állítása nem bizonyíték.
- **NEM MEGERŐSÍTETT**, hogy a két csomag a projekt kilenc lint szabálya (`no-explicit-any`,
  `no-unsafe-*`) mellett `eslint-disable` nélkül használható; a `@types/mustache` több helyen
  `any` típust deklarál (pl. `EscapeFunction = (value: any) => string`). A PLAN-010 F0 méri.
- **NEM MEGERŐSÍTETT** semmilyen időkorlát, lépésszám vagy kimeneti méret szám a két csomagra; a
  4.7 sor a `cel-go` értékeit csak azért rögzíti, hogy látszódjon, a referencia implementáció
  milyen korlátokat dokumentál. A mi csomagunkra nem vesszük át őket.
